# nucleus (Flutter client)

Flutter client for the Nucleus cloud storage aggregator. See the repo root
[`README.md`](../README.md) and [`docs/PLAN.md`](../docs/PLAN.md) for product context.

Currently a Phase 0 scaffold — a placeholder harmonized-view screen with no provider
connections or sync engine wired up yet.

```bash
flutter pub get
flutter run -d macos   # or windows / chrome / linux
```
